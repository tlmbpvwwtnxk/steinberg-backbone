## Overview

Backbone combines sample playback with physical-modeling synthesis, stretching the transient and body of drum samples independently, letting you sculpt kick, snare, and cymbal sounds from any source.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Steinberg Backbone** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Transient Stretch** | Independent time-stretch of attack transient separate from body |
| **Body Synthesis** | Physical-model synthesis replaces or augments the sample body |
| **Layer Mixing** | Up to eight sample and synthesis layers with individual level and pan |
| **Spectrum Match** | Match the spectral envelope of any reference drum sound |
